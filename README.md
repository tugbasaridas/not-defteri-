# not-defteri-
Basit bir Not Defteri (Notepad) uygulaması — C# ile yazıldı.

Bu repo bir masaüstü not defteri uygulaması içerir (ör. WinForms veya WPF). 

## Özellikler
- Yeni not oluşturma
- Dosya açma (.txt)
- Kaydet / Farklı Kaydet
- Kes / Kopyala / Yapıştır
- Bul & Değiştir (isteğe bağlı)
- Yazdırma desteği (isteğe bağlı)
- UTF-8 dosya kodlamasıyla uyumluluk

## Gereksinimler
- .NET SDK 6.0 veya daha yeni (projeye göre 7.0 ya da 8.0 belirtin)
- Visual Studio 2022/2023 veya VS Code + C# eklentisi (tercihe göre)
